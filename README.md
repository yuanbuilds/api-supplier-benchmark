# 供应商模型自测

同一套 EvalScope 1.13.0 引擎，按模型选择固定方案。

- **Kimi K3**：[运行说明](KIMI_K3_test_README.md)，连通1次 + C1两轮各10次 + C4共12次，合计33次。
- **GLM 5.3**：[运行说明](GLM5.3_test_README.md)，原有706次与200 RPM三分钟方案保持。

请按所选说明克隆和启动；隐藏输入Key，先看计划，完成后回传唯一ZIP。程序版本2.3.0；自测不等于商业准入，报告中的模拟结果不代表真实供应商。
